# Myspace

## 🏍️ Interceptor 650 Cost Tracker

An interactive, single-file cost-of-ownership tracker for the **Royal Enfield
Interceptor 650**. Open [`interceptor-650-cost-tracker.html`](interceptor-650-cost-tracker.html)
in any browser — no install, no server, no dependencies.

### Features
- **On-road purchase breakdown** — ex-showroom, RTO/road tax, insurance, accessories (editable rows).
- **Recurring costs** — yearly insurance, servicing, consumables.
- **Fuel & running cost calculator** — live cost per km / month / year from your mileage and fuel price.
- **Service & maintenance log** — date, work done, odometer and cost per entry.
- **Cost of ownership summary** — purchase amortised over your ownership period, with a per-year breakdown.
- **Auto-save** — everything persists in the browser via `localStorage`.
- **Export CSV** and **Print/PDF**; switch currency (₹ / $ / £ / €).

### Usage
Double-click the HTML file (or open it in a browser). Edit any cell and totals
recalculate instantly. Use **Reset all** to restore the sample data.

> Figures are estimates — adjust them to match your local prices and riding habits.
