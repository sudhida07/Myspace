# Myspace

A simple, browser-based expense tracker.

## Run it

Just open `index.html` in any modern browser — no build step, no server.

## Features

- Add expenses with amount, category, date, and an optional note
- Live totals: overall, current month, and entry count
- Spend breakdown by category with a relative bar
- Search by note or category
- Export all expenses to CSV
- Data persists in your browser via `localStorage` (private to your device)

## Files

- `index.html` – markup
- `styles.css` – styling (dark theme)
- `app.js` – logic and storage
